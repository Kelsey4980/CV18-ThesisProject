# BEFORE installing this file, install the CUDA-matched PyTorch stack separately —
# these are NOT reliably resolvable from plain PyPI:
#
#   pip install torch==2.3.1+cu118 torchvision==0.18.1 torchaudio==2.3.1 \
#       --extra-index-url https://download.pytorch.org/whl/cu118
#
# Then build/install PyTorch3D against that torch build (from source is recommended;
# it must be compiled against the exact torch/CUDA version above):
#
#   FORCE_CUDA=1 pip install "git+https://github.com/facebookresearch/pytorch3d.git@stable"
#
# System-level prerequisites this file does NOT cover (install via conda/OS package
# manager, not pip): CUDA 11.8 toolkit + driver, GCC ~11.x (for building extensions),
# ffmpeg (used by decord/video I/O).
#
# NOTE: this env has opencv-contrib-python, opencv-python, AND opencv-python-headless
# installed simultaneously. These share the same cv2 import namespace and having more
# than one installed is redundant (and can cause import conflicts depending on install
# order). Recommend keeping only opencv-python-headless for a headless HPC environment
# unless you specifically need contrib modules.
